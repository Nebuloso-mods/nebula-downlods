Solicitação de Exclusão de Dados

Caso deseje excluir sua conta ou os dados armazenados pelo Portal Nebuloso, envie uma solicitação para o e-mail do desenvolvedor.

Após a confirmação, seus dados serão removidos do Firebase dentro de até 30 dias.

Dados que podem ser excluídos

  • Nome
  • E-mail
  • Foto do perfil
  • Mensagens enviadas no chat (quando aplicável)
