Política de Privacidade

Última atualização: 28/06/2026

1. Dados coletados

O Portal Nebuloso utiliza o Firebase Authentication para autenticação dos usuários através de Google, Facebook ou acesso como visitante.

Quando o usuário realiza login, podem ser utilizados:

  • Nome
  • Foto de perfil
  • E-mail (quando disponível)

Essas informações são utilizadas apenas para identificação dentro do aplicativo.

2. Chat da comunidade

As mensagens enviadas no chat ficam armazenadas no Firebase Firestore para permitir a comunicação entre os usuários.

3. Compartilhamento

O Portal Nebuloso não vende nem compartilha dados pessoais com terceiros.

4. Segurança

São utilizadas as tecnologias do Firebase para armazenamento e autenticação dos usuários.

5. Exclusão dos dados

O usuário pode solicitar a exclusão de seus dados conforme descrito na página de Exclusão de Dados.

Clique aqui para solicitar a exclusão de dados.

6. Contato

Caso tenha dúvidas, entre em contato pelo e-mail informado pelo desenvolvedor.
